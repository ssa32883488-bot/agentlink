# 三端 UI 视觉区分设计

**版本**：2026-10-27  
**范围**：采购商 / 供应商 / 物流 控制台（共用 `ui/static`，按角色换肤）

## 目标

一眼分清「我是谁」：顶栏标题更大、角色色条 + 角色徽章，三端色相不混用。

## 角色主题

| 角色 | body class | 主色 | 顶栏标题示例 |
|------|------------|------|--------------|
| 采购商 | `role-buyer` | 蓝 `#2563eb` → 青蓝 | 采购商A · 采联控制台 |
| 供应商 | `role-supplier` | 青绿 `#0d9488` → 翠绿 | 供应商A · 供应控制台 |
| 物流 | `role-logistics` | 琥珀 `#d97706` → 金 | 物流智运 · 物流控制台 |

## 视觉元素

1. **顶栏顶边色轨**（3px）：`var(--role-rail)`  
2. **标题 `.logo`**：约 `1.45rem`、字重 900、渐变字色  
3. **角色徽章 `.role-chip`**：采购商 / 供应商 / 物流  
4. **页内 `h2`**：约 `1.28rem`、字重 800  
5. **侧栏激活态 / 主按钮 / 用户气泡**：跟随 `--accent`

## 实现

- `styles.css`：`:root` 默认采购蓝；`body.role-*` 覆盖变量  
- `app.js`：`resolveUiRole` + `applyRoleTheme`（加载域、切换智能体时调用）  
- 各 `config_*.yaml`：`domain_title` 文案区分「采联 / 供应 / 物流」

## 非目标

本版不改布局结构、不改业务 API；组群沙盒聊天室另案。
