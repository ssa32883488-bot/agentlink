## 平台入口（拿到后填写）

在 `.env` 或 `config/acps_platform.yaml`：

```text
ACPS_REGISTRY_URL=
ACPS_REGISTRY_MTLS_URL=
ACPS_CA_URL=
ACPS_DISCOVERY_URL=
ACPS_PUBLIC_ENDPOINT=   # 各 Agent 可按 ACS endPoints 分别配置
ACPS_REGISTRY_USER=
ACPS_REGISTRY_PASSWORD=
```

提交预检：

```powershell
cd F:\code\智能体协议\项目开发\agentlink
.\.venv\Scripts\python.exe -m scripts.enroll_platform --agent buyer-a
# 六份 ACS 亦可在官网控制台逐个上传 acs/*.acs.json
```

审核通过后：把真实 AIC 写入各机 `/opt/agentlink/.env`（如 `BUYER_A_AIC=...`），再申领证书并打开 `AIP_IDENTITY_BINDING=1`。
