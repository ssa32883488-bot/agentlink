# 对话驱动：货物订单 → 再对话物流下单

**日期**：2026-10-30  
**对齐用户流程**：平台发现 → 人选供应 → 对话询价/议价 → 人确认货物单 → 提示联系物流 → 对话询运 → 人确认物流单。

## 流程

```
采购 --ADP发现--> 梧桐平台 --列表--> 人类勾选供应
采购 --询价/议价对话--> 供应商（货价·规格·活动门槛）
人类确认 → 双方确认货物工单 → 订单生效
        → 提示「去和物流询价下单」（不自动拉单）
采购 --询运对话--> 物流
人类确认 → flow.place_logistics_order → 采购↔物流工单双方确认 → 承运生效
```

## 关键改动

| 项 | 行为 |
|----|------|
| `_maybe_start_logistics` | 只提示 + 按钮，**不** auto spawn |
| `flow.place_logistics_order` | 人类确认后由采购生成物流工单 |
| 询价 `need_freight` | 默认 `false`（货物流与物流流分离） |
| 采购 Wit 提示词 | 两段主流程写死 |

## 手测话术

1. 「我打算购买 300 套重型脚轮，请发现供应商并报价」  
2. 人选供应 A → 问优惠 → 改 500 套正式下单 → 双方确认工单  
3. 点「去和物流询价下单」→ 说明沧州→保定与体积 → 确认后下物流单 → 双方确认
