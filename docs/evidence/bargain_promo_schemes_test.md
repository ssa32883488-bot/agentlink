# 议价满减 / 跨省补贴 / 多方案 · 白话测试记录

**日期**：2026-10-27  
**测什么**：议价是不是还在死压单价；三家满减、山西跨省补贴、拆单方案有没有出来；要不要强迫采购报预算。

## 怎么测（人话）

1. 本地跑 `scripts/_smoke_bargain_schemes.py`：不连云，直接算促销与方案。  
2. 中等采购量（220 件）：看能不能生成「维持现量 / 凑满减 / 拆单」。  
3. 大采购量（500 件）+「预算紧」姿态：看推荐是不是更偏向拆单（山西库存不够）。  
4. 「预算宽裕」姿态：看推荐是不是更偏向凑满减。  
5. 单独验山西：150 件出省，运费补贴要打上「不确定」。  
6. 旁观者 LLM 对照设计文档挑刺。

## 实测结果

- **结论：PASS**
- 中等量方案种类：`single_as_is`、`single_reach_promo`、`split_order` 齐全  
- 大量 + 预算紧：推荐 `S3-split-c-supplier-a`（山西能供的拿一点，缺口河北补）  
- 预算宽裕：推荐靠前为 `S2-reach_full_reduction-supplier-a`（凑沧州满减）  
- 山西补贴：`applied=true`，`uncertain=true`（补贴约 175 / 运费 500）  
- **`budget_required=false`**：不要求采购先报预算也能出方案
