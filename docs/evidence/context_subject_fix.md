# 采购对话主体串台修复 · 白话记录

**日期**：2026-10-27  
**现象**：用户在谈「扶手 RM-ARMREST ×500」，助手后半段却扯到「脚轮 RM-CASTER-300」和旧比价案。

## 根因（人话）

1. `flow.status` 在本窗没有采购案时，会偷偷挂上**全库最新一案**（经常是脚轮）。  
2. 跨窗共享记忆只写了「净采购 500」，**没绑物料**，下一窗也能乱套。  
3. `discover.suppliers` 默认品名是「重型脚轮」，容易在没传参时开错案。

## 怎么改的

1. `flow.status` **不再**自动改绑历史案。  
2. 采购案绑到**对话窗**；切窗只恢复本窗的案。  
3. 发现供应商时：品名必填；与旧案物料不符就**新开案**。  
4. 共享记忆写数量时自动带上本案 `product`。  
5. 系统提示强调：本窗主体物料不可偷换。
