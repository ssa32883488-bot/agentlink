# 下一步可选 · 做成按钮 + 补充 · 白话记录

**日期**：2026-10-27  
**吐槽点**：比价后助手写出「1/2/3 下一步可选」，还得自己打字，没有可点按钮。

## 改了什么

1. 询价/比价回执自动带 `choice_actions`（议价 / 选最低价下单 / 先问补贴）。  
2. 新增工具 `ui.offer_choices`：凡要给人做选择，必须出结构化按钮。  
3. 前端底部 `choiceDock`：可点按钮 + 可选「补充说明」输入框。  
4. 提示词铁律：禁止只甩文字编号清单。

## 怎么用（人话）

比价出来后，聊天框**下方**会出现按钮；可先在补充框写一句，再点按钮。  
点了之后等于帮你把话发给助手去执行。
